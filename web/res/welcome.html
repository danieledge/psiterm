PsiWeb

NetSurf for the Psion Series 5mx. Pages are HTML and CSS only: no JavaScript.

Light sites that work well

  • 68k.news - news headlines for vintage computers
  • FrogFind - web search, pages simplified
  • DuckDuckGo Lite - search
  • NPR text and CNN lite
  • Wikipedia (mobile pages)
  • wiby.me - a search engine for simple pages

Keys

  • Ctrl+L open an address or search   Ctrl+B back   Ctrl+F forward
  • Esc stop loading   Ctrl+R reload   Ctrl+H home page
  • Fn+Up/Down page up/down   Ctrl+M zoom in, Shift+Ctrl+M zoom out
  • Tap links and form fields with the pen

Connecting: Tools > Connection settings (the same modem or dial-up link as PsiTerm). For speed, point Tools > Proxy at a WebOne proxy on your network: it fetches HTTPS pages for the Psion and shrinks images.
