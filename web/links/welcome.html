PsiWeb

A web browser for the Psion Series 5mx. Pages are shown as plain documents: no JavaScript and no style sheets. Pictures are fetched only when you ask: View > Show pictures (Ctrl+I).

Light sites that work well

  • 68k.news - news headlines for vintage computers
  • FrogFind - web search, pages simplified
  • DuckDuckGo Lite - search
  • NPR text and CNN lite
  • Wikipedia (mobile pages)
  • wiby.me - a search engine for simple pages

Keys

  • Ctrl+O open an address or search, Ctrl+H home page, Ctrl+R reload
  • Ctrl+B back, Ctrl+F forward, Esc stop loading
  • Fn+Up and Fn+Down page up and down, Ctrl+M and Shift+Ctrl+M zoom
  • Tap links and form fields with the pen; type into a field once it is chosen

Connecting: Tools > Connection settings (the same modem or dial-up link as PsiTerm and PsiMail). For speed, set a WebOne proxy in Tools > Preferences: it fetches https pages for the Psion and shrinks pictures.
